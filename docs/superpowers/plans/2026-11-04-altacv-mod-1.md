# altacv-mod-1 implementation plan

Approved specification: replace both existing layouts with the design in
`typst-work`, using bundled AltaCV 1.7.0 and its dependencies. Default to Lato
10 pt, teal, one column and native 9 mm horizontal / 15 mm vertical margins.
Retain clean and annotated PDFs, plain PDF metadata, German localization,
all/compact education details, long-entry pagination, profile links and issuers.
`altacv1` normalizes to `altacv-mod-1`; old layout names are rejected. Optional
uniform margins, font and size overrides remain available. Scope is existing CV
data: no new focus-area, award, photo or numeric-language-rating pipeline.

1. Add failing configuration and PDF regression tests; preserve and retarget the
   existing uncommitted education regressions.
2. Bundle pinned packages, licenses and fonts. Adapt the typed render model and
   service, add the thin AltaCV wrapper and minimal upstream extensions, remove
   the old layouts, and get focused tests passing.
3. Recalibrate layout defaults using native settings; update usage and provenance.
4. Check the built wheel with empty caches, inspect clean/annotated/long PDFs,
   run the full offline suite and lint/type/import checks, and obtain fresh review.

Verification: pytest; ruff check; ruff format --check; mypy; lint-imports;
calibrate_layout.py; installed-wheel smoke render; rendered-page visual review.
